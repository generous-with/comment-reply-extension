# AI 评论回复助手

<img src="assets/icon-128.png" width="96" height="96" alt="AI 评论回复助手 Logo">

Chrome / Edge Manifest V3 扩展。点击评论旁的“回复”，结合评论与作品标题生成简短、自然的回复，自动填入对应输入框，由你审核后手动发布。

支持豆包网页版和 OpenAI 兼容 API。当前版本：0.6.3，MIT 开源。

如果觉得回复像模板，在设置的“我的表达样本”贴 2–3 条自己写过的回复，或一小段自己写的知乎回答。豆包和 API 都会参考语气、用词和句子长短，样本中的经历或结论不会当成本次回答的依据。知乎默认不再要求凑字数，短评论优先回应一个具体点。已有短评论自定义提示词会保留。

豆包生成后，扩展按本次请求的完整标记取回结果。即使停止按钮未及时消失，完整答案稳定后也能切回；若读取失败，会在原页面给出原因。生成期间手动切到其他标签页时，扩展不会抢回焦点。

### 知乎回答

打开 `https://www.zhihu.com/question/数字ID` 的问题页，点“写回答”→“AI 生成知乎回答”。扩展展开并读取问题描述，结合标题和作者背景生成正文、一句话介绍及可选配图建议。知乎有单独的长回答提示，不受评论字数设置限制。

生成后可在“查看生成草稿和配图建议”查看三部分内容。需要配图时，使用“插入图片”打开知乎原生图片工具，选择本地图片。扩展会将创作声明设为“包含剧透”，并尝试开启送礼物；首次弹出赞赏协议时请阅读并确认，然后点“填写一句话介绍”。简介填入知乎“编辑话题经验”弹窗后，请核对并自行保存。已有草稿可以点击“设为包含剧透”单独更新声明。发布由你完成。

Logo 采用对话框、回转回复箭头与星芒，矢量源文件在 `assets/logo.svg`，提供 16/32/48/128/512 像素 PNG。使用 Pillow 运行 `python scripts/export-icons.py` 可重新导出；图形随项目以 MIT 许可证开源。

设置页提供可编辑的“回复提示词”，豆包和 API 共用。默认采用 AI 大模型开发、运维专家身份，以自然的 1–3 句话回复；可自行修改，并通过“恢复默认提示词”恢复，保存后生效。升级旧配置自动显示默认值；留空也使用默认值，已有 API 和豆包会话配置保留。扩展会继续补充当前评论、作品信息、字数限制和事实约束。

## 支持的页面

| 站点 | 使用位置 | 上下文 |
| --- | --- | --- |
| B站 | 消息中心“回复我的” `message.bilibili.com/#/reply` | 被点击评论及可读参考内容 |
| 今日头条 | 创作者后台评论管理 `mp.toutiao.com/profile_v4/manage/comment/all` | 主评论与对应作品完整标题 |
| 抖音 | 创作者中心具体作品详情的“评论管理” | 当前作品描述、作品 ID 与目标评论；支持已展开子评论 |
| 知乎 | 问题页“写回答” | 问题标题、展开后的描述和作者背景 |

抖音填写评论下方的回复框。扩展不点击发表或发送按钮，不批量发布评论。

## 安装

1. 在 [Releases](https://github.com/generous-with/comment-reply-extension/releases) 下载最新安装 ZIP 并解压；也可克隆仓库直接加载根目录，无需编译。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
4. 点击扩展图标打开设置，选择回复来源并保存。
5. 刷新评论页面，点击某条评论的“回复”，等待填写，审核后手动发布。

升级时覆盖原目录，重新加载扩展，并刷新评论页和豆包页。同一路径通常可保留原扩展设置。

## 豆包网页模式（试用）

在同一浏览器登录豆包，设置中选择“豆包网页版”。会话地址留空可新建会话，也可填写你自己的 `https://www.doubao.com/chat/数字ID` 专用会话。

扩展维护自己的豆包标签页，把评论、作品信息、作者背景和回复要求提交给豆包，取回完整回答后填入原评论。默认要求以 AI 大模型开发、运维专家视角回复，用自然的 1–3 句话表达，避免生硬套话。网页模式无需配置 API Key，仍使用豆包模型服务。

一次只处理一条请求。专用豆包页面有草稿、正在生成或登录失效时会停止；不要在生成期间手动编辑该会话。完整回答按本次随机标记提取，最长等待约 150 秒。网页改版可能影响适配。

## OpenAI 兼容 API

选择 API 模式，填写 Base URL、模型和 Key；例如 `https://api.example.com/v1`（示例域名，须替换）。远程地址必须使用 HTTPS，本机 localhost/127.0.0.1 可用 HTTP。保存时授权你配置的服务域名。“测试连接”会向所选回复来源提交测试问题。

作者背景可补充项目事实和回复偏好；标题只作为话题线索，提示词要求不根据标题编造技术细节。生成内容仍需审核。抖音回复上限为 500 字，超长结果提示错误。

## 数据与权限

- `storage` 保存配置；API Key 限扩展可信上下文读取，不传入页面脚本、DOM 或豆包提示词。
- `scripting` 用于恢复扩展自管豆包标签页的桥接脚本；固定访问权限仅限豆包，评论站点通过声明的内容脚本适配。
- API 域名按需授权。使用 API 时，选定评论、作品信息、参考内容及作者背景会发送到你配置的服务；网页模式发送到豆包。
- 不读取 Cookie。仓库和安装包不包含用户会话地址、登录资料、个人配置或真实密钥。
- 回复框已有手写内容、目标评论改变或切换作品时保护原有输入。页面重绘时仅尝试重新定位相同目标的唯一空框。

## 开发与验证

运行时为原生 JavaScript，无生产依赖、无需构建。开发测试需要 Node.js 22+：

```sh
npm install
npx playwright install chromium
npm test
```

可用 `BROWSER_EXECUTABLE_PATH` 指定已安装浏览器路径，`PLAYWRIGHT_PATH` 指定 Playwright 模块。实际扩展往返测试需要安装 Edge：

```sh
npx playwright install msedge
npm run test:smoke
```

可通过 `EDGE_EXECUTABLE_PATH` 指定 Edge 路径。Smoke 使用隔离浏览器资料和受控站点/API，产物写入被 Git 忽略的 `evidence/`。测试验证评论定位、上下文、手写保护、重绘恢复、豆包桥接和答案标记提取；不等同于登录实站或真实模型验收。

已知限制：今日头条目前仅主评论；豆包网页模式仍为试用；站点动态类名与页面结构变化需要更新适配。0.5.4 的抖音同作品路由事件及同评论重开回归已通过受控测试，用户真实页面仍需验证。

## 源码与适配依据

`ai-background.js` 管理消息与配置，`ai-core.js` 构造 API 请求及回复要求；三个站点的 `*-content.js` 负责提取和填写。`doubao-worker.js` 管理专用标签页，`doubao-content.js` 执行网页交互，`doubao-answer.js` 提取本次回答。

选择器依据 2026-10-30 获取的公开站点业务资源，URL、哈希及选择器摘要见 [docs](docs/)。只发布来源元数据，不分发平台业务源码或浏览器资料。
